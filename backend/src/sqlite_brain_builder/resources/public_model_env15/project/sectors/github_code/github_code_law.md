# Env15 GitHub Code Sector Law

- Sector ID: `github_code`
- SQLite: `project/sectors/github_code/github_code_sector_v001.sqlite`
- Public model read: allowed.
- Automatic normal-turn write: not allowed.
- Mutation: explicit named one-turn grant, validation, mutation receipt, immutable snapshot and immediate relock.
- Env mutation: forbidden.
- UOP override: forbidden.
