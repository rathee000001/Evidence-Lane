# Security and Controlled Quarantine Notice

The app uses a documented, visible, data-preserving quarantine model. Do not edit installed binaries/manifests, bypass security gates, modify exported env/uop locks, inject bypass instructions, store secrets in packages, or repackage as official builds without signature. If an integrity gate fires, builds/exports stop, user data stays readable, and a local receipt is written.

No stealth process, destructive crash/corruption, covert data upload, or custom crypto trap is implemented in this candidate.
